uvx / pip

Install & run MCP

Requires Python ≥ 3.11 and ansible-core on PATH for real runs.

# one-shot
uvx --from ansible-flow-mcp ansible-flow-mcp

# editable dev
git clone https://github.com/real-limitless/ansible-flow-mcp.git
cd ansible-flow-mcp
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest -q
ansible-flow-mcp
