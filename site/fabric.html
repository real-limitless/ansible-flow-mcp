The hub is the only door

Secure multi-host mode: the agent attaches to the hub only. Hub reaches spokes over SSH only. Spokes execute localhost and cannot lateral-move via this fabric.

Ops model Mesh OS Classic bastion
Dual SSH identities — never conflate them. Mesh hop uses the hub client key + ForceCommand user for spoke_call. Ansible runs use a separate identity. Putting interactive Ansible expectations on a ForceCommand-only user deadlocks runs.
